# Legacy external-AI line-review archive

The external-AI geometry-and-text workflow was retired on 2026-08-30. This directory is retained only as provenance for work already returned, evaluated, or imported; it is not a queue of current assignments.

## Preserved scope

- Base task JSON for `f31`–`f125`, because those records are the inputs against which returned reviews were made.
- Every returned `*-reviewed.json`, `*-rereviewed.json`, and `*-reviewed-redone.json`, including incomplete, rejected, and superseded returns. Their limitations are part of the evidence.
- The response specification, geometry guide, and import log needed to interpret those frozen files.
- The independent f30 structural specimen in [`../ai-geometry-examples/`](../ai-geometry-examples/).

Unused prepared task JSON outside the returned-review range was deleted rather than maintained as a stale future queue. The ignored native-image ZIP archive is likewise retained only for `f31`–`f125`; later packages were deleted. Canonical transcription and geometry remain in their normal project files and are not replaced by this archive.

## Interpretation

A returned file was never automatic authority. Its geometry entered the canonical record only after project-side validation; its textual disagreements were separately adjudicated against the scan. Consult the [import and provenance log](IMPORT-LOG.md) for those decisions.

The preserved [response format](FORMAT.md) and [geometry guide](GEOMETRY-GUIDE.md) describe the retired protocol as it operated. They must not be read as instructions to resume it. If a future experiment revisits delegated review, generate fresh inputs from the then-current transcription and geometry under a newly documented workflow.
